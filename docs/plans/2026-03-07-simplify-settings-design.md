# 设置界面简化设计

## 概述

简化桌面宠物的设置界面，移除不必要的用户自定义选项，降低使用门槛。

## 背景

当前设置界面功能过于复杂，用户需要配置：
- 宠物名字
- 完整的人设提示词
- 状态动画图片

这些功能对于大多数用户来说不是必需的，增加了使用成本。

## 设计目标

1. 固定助手名字为"皮卡丘"
2. 人设提示词使用固定前缀，用户仅需补充"主要职责"
3. 移除状态动画图片上传功能
4. 代码中预留扩展点，便于后续支持自定义

## 详细设计

### 1. 设置界面变更

#### 基础标签页

**移除：**
- 宠物名字输入框（固定为"皮卡丘"）

**修改：**
- 人设提示词 → 改为"主要职责"文本框
  - 前缀固定显示为提示文本，不可编辑
  - 用户仅能输入主要职责内容

**保留：**
- API 配置（地址、Key、模型）
- 用户偏好列表

#### 状态标签页

**移除：**
- 动画文件浏览/上传功能
- 对话文本配置

**保留：**
- 宠物尺寸设置（小/中/大 + 自定义）
- 聊天窗口尺寸设置

### 3. 代码变更

#### core/persona.py

```python
# 默认常量
DEFAULT_NAME = "皮卡丘"
DEFAULT_PROMPT_PREFIX = "你是一个电气老鼠宠物，你的主要职责是："

def build_system_prompt(user_duties: str = "") -> str:
    """构建完整人设提示词

    Args:
        user_duties: 用户自定义的主要职责描述

    Returns:
        完整的人设提示词
    """
    if not user_duties or not user_duties.strip():
        user_duties = "陪伴用户、聊天解闷"
    return DEFAULT_PROMPT_PREFIX + user_duties.strip()
```

#### config.yaml

```yaml
persona:
  name: 皮卡丘  # 固定值
  duties: ""   # 用户自定义主要职责（新增字段）
  user_preferences: []
```

#### ui/settings_dialog.py

- 移除 `self.name_input` 输入框
- 将 `self.prompt_input` 改为 `self.duties_input`
- 添加固定前缀提示标签
- 移除状态标签页中的动画配置相关代码
